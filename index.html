Sobre o sistema

O sistema dos Bolos da Neide serve para organizar as encomendas de bolos da Dona Neide, trocando o caderno e os papéis soltos por um sistema de computador que controla clientes, datas de entrega, status dos pedidos e pagamentos, com letras grandes para facilitar a leitura.

Site em construção: novas funcionalidades serão adicionadas em breve.

Principais funcionalidades

  • Cadastro de clientes
  • Registro das encomendas de bolos
  • Controle das datas de entrega
  • Acompanhamento do status dos pedidos
  • Controle de pagamentos
  • Taxa de urgência de 30% aplicada automaticamente nos pedidos urgentes
  • Interface com letras grandes para facilitar a leitura
  • Visual nas cores rosa bebê e branco
